Transcripts: .srt, .vtt or .txt (from DaVinci Resolve, Descript, Otter, Rev, Premiere, YouTube…). From Resolve: transcribe the clip, then on a timeline use Create Subtitles from Audio and File › Export › Subtitle… (.srt); times that start at 01:00:00 are moved back to 00:00 automatically. Timelines: FCPXML from Final Cut Pro or DaVinci Resolve, or XML from Premiere Pro. Transcripts link to clips with the same name so their timecodes line up.

Transcripts are the biggest thing in a project. Keep them in this browser's file storage, or as files in a folder such as a shared Google Drive folder, so the project itself stays small enough to share and sync quickly. Each transcript shows where it's kept and where it's been.

Where everyone keeps the media

When you pass a project around, everyone's footage lives somewhere different. Note each person's folders here, then pick their name under “Clip paths for” on the Export Timeline tab: the exported timeline points at their copies, so Resolve finds the clips without relinking. In Resolve itself, right-click clips in the Media Pool › Change Source Folder… does the same for one project.
