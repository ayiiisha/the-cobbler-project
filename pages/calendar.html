How to share it so it stays up to date
  1. Download the file and put it in a folder you all share (Dropbox, Google Drive, iCloud Drive). It always has the same name: next time, replace the old one.
  2. Get a link that downloads the file straight away. In Dropbox: Copy link, then change the dl=0 at the end to dl=1.
  3. Everyone subscribes to that link once:
    • Apple Calendar: File › New Calendar Subscription…
    • Google Calendar: Other calendars › + › From URL
    • Outlook: Add calendar › Subscribe from web
  4. When dates change, download it again and replace the file. Subscribed calendars update by themselves (Google can take up to a day).

No shared folder? Send the file round: opening it again updates the same events rather than doubling them in Apple Calendar and Outlook.
