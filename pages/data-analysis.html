Load a CSV to see a profile of each column, filter it and draw a quick chart. The page writes matching R code (tidyverse and ggplot) to copy into RStudio. It doesn't run R itself.

R code

Save the R script in the same folder as your CSV, then open it in RStudio and run it. The code is written here on the page, so this works offline.

Datawrapper: running the script needs an internet connection, the httr2 package and your Datawrapper API token (the comments in the code explain how to set it up). The chart appears in your Datawrapper account; the preview above shows the same numbers.
